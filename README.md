# Vehicle Service Management Application

## Project Overview

The Vehicle Service Management Application is designed to manage the end-to-end vehicle servicing process.

The application allows customers to raise service requests, provides vehicle inspection and estimate preparation, manages customer approvals, coordinates service execution, and sends service notifications.

## Main Case Types

- Service Request
- Vehicle Inspection
- Service Approval
- Service Execution
- Service Notification

## Key Features

- Customer vehicle service request
- Vehicle and issue details collection
- Vehicle inspection
- Service estimate preparation
- Customer approval or rejection
- Technician assignment
- Service execution tracking
- Quality verification
- Customer notifications
- Service request closure

## Data Objects

The application uses data objects including:

- Customer
- Vehicle
- Service Request
- Service Estimate
- Service Advisor
- Technician
- Service Progress Log
- Approval Record
- Notification
